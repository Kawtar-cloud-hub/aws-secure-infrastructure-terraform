# Secure AWS Infrastructure Deployment with Terraform

This repository contains a production-ready Infrastructure as Code (IaC) template using Terraform to provision an isolated AWS Virtual Private Cloud (VPC), secure S3 bucket with server-side encryption, and fine-grained IAM roles.
